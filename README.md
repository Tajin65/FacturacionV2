# FacturacionV2

Versión profesional base para catálogo, cotizaciones, facturas proveedor CFDI y mano de obra.

## Incluye
- README completo
- `.gitignore`
- React + TypeScript + Vite
- importación/exportación JSON desde UI
- CRUD de productos, empleados, clientes y contactos
- edición/eliminación
- parser mejorado de conceptos CFDI
- lista de facturas guardadas
- módulo de costo de mano de obra

## Recomendaciones para costo de mano de obra
Conviene incluir:
- salario base por técnico
- número de técnicos
- días de instalación
- supervisor
- IMSS / cargas sociales
- viáticos
- transporte
- herramientas y EPP
- renta de equipo
- ingeniería / administración
- indirectos
- utilidad

## Ejecutar

npm install
npm run dev
